# Long Beach Animal Shelter

A data set containing animals admitted to Long Beach Animal Shelter from
January 1, 2017 to January 1, 2025.

## Usage

``` r
longbeach
```

## Format

A data frame with 29787 rows and 23 variables.

## Source

<https://data.longbeach.gov/explore/dataset/animal-shelter-intakes-and-outcomes/information/>
